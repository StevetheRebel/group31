## MVP

The Minimum Viable Product focuses on two core customer support functions:

1. Order Status Lookup
2. Stock Availability Lookup

The prototype will allow users to check order information using an order ID and search product availability using relevant product information.

## Core Features

### Order Status Lookup

Users will be able to:

- Enter an order ID.
- Retrieve the current order status.
- View relevant delivery information.
- Receive an appropriate response when an order cannot be found.
- Receive escalation instructions where required.

### Stock Availability Lookup

Users will be able to:

- Search for a product.
- Check product availability.
- Check relevant size and colour information.
- View stock status.
- Receive appropriate responses for unavailable products.
- Receive escalation instructions where required.
